# آرکا (Arka VPN) — راهنمای فارسی

## 📦 چی توی این نسخه واقعی شد؟
از این نسخه به بعد، آرکا یک **تونل VPN واقعی** داره — نه شبیه‌سازی:

- **هسته**: `libv2ray.aar` واقعی، دانلود و کامیت‌شده از پروژه‌ی رسمی
  [2dust/AndroidLibXrayLite](https://github.com/2dust/AndroidLibXrayLite) — دقیقاً همون Xray-core
  که **v2rayNG** (محبوب‌ترین کلاینت V2Ray اندروید) استفاده می‌کنه.
- **ArkaVpnService**: یک `VpnService` واقعی که رابط TUN واقعی می‌سازه و فایل‌دسکریپتورش رو مستقیم
  به هسته می‌ده.
- **ConfigConverter**: لینک‌های vless/vmess/trojan/ss ذخیره‌شده رو به یک کانفیگ JSON معتبر Xray-core
  تبدیل می‌کنه (outbound + tun inbound + dns + routing).
- **پینگ و آمار ترافیک واقعی**: از خود هسته خونده می‌شن (`measureDelay`, `queryAllOutboundTrafficStats`)
  — دیگه رندوم نیستن.

### چیزی که هنوز TODO هست

- IPv6 کامل (فعلاً فقط IPv4 روی TUN تنظیم شده).

## 📦 محتوای پروژه
- Kotlin + Jetpack Compose (تیره، فارسی، RTL)
- Room (دیتابیس محلی، دیدوپ با SHA-256) + Coroutines
- ۵ فایل کانفیگ در `app/src/main/assets/` (fast/normal/hard/stable/usa.txt)
- دیالوگ مدیریت کانفیگ (⚙): ایمپورت از فایل‌ها، ایمپورت از کلیپ‌بورد، پاک کردن دیتابیس
- `app/libs/libv2ray.aar` — هسته‌ی واقعی VPN (~۵۹ مگابایت، شامل باینری‌های native برای هر ۴ معماری)

## 🐙 بخش ۱: ساخت APK با GitHub Actions

### مرحله ۱ — ساخت مخزن جدید
به [github.com/new](https://github.com/new) برو، یک مخزن جدید بساز، مثلاً به اسم `arka-vpn`.

### مرحله ۲ — آپلود همه فایل‌ها
محتوای ZIP رو extract کن و با همین ساختار (شامل `.github/workflows/build.yml`، `app/libs/libv2ray.aar`،
`app/`، `gradle/`, `settings.gradle.kts` و...) توی ریشه‌ی مخزن push کن:
```bash
git init
git add .
git commit -m "اولین نسخه آرکا با هسته واقعی"
git branch -M main
git remote add origin https://github.com/USERNAME/arka-vpn.git
git push -u origin main
```
> ⚠️ فایل `libv2ray.aar` حدود ۵۹ مگابایته. گیت هنگام push یک هشدار درباره‌ی فایل‌های بزرگ می‌ده
> (حد مجاز گیت‌هاب ۱۰۰ مگابایته) — طبیعیه، push موفق می‌شه.

### مرحله ۳ — اجرای Workflow
تب **Actions** → روی «Build Arka VPN APK» → **Run workflow**.

### مرحله ۴ — دانلود APK
بعد از سبز شدن، از بخش **Artifacts** فایل `app-debug` رو دانلود کن (داخلش `app-debug.apk`).

## 🧪 بخش ۲: راهنمای تست (این بار واقعی)

1. **نصب APK**: روی گوشی اندروید ۸ (API 26) به بالا نصب کن.
2. **باز کردن اپ**: صفحه‌ی اصلی رو ببین.
3. **اتصال واقعی**: یک حالت (مثلاً «عادی») رو انتخاب کن → دکمه‌ی وسط رو بزن.
   - اول کانفیگ‌های همون بخش با TCP واقعی تست می‌شن (حلقه پر می‌شه).
   - وقتی یکی سالم پیدا شد، **دیالوگ سیستمی اندروید برای اجازه‌ی VPN** باز می‌شه — قبولش کن.
   - بعد از چند ثانیه، هسته‌ی Xray-core واقعی بالا میاد و «متصل» سبز می‌شه.
4. **تست اینترنت واقعی**: مرورگر گوشی رو باز کن و یک سایت که مسدوده رو امتحان کن — این بار باید
   واقعاً از تونل رد بشه (چون هسته‌ی واقعیه، نه شبیه‌سازی).
5. **تست IP**: به [ipapi.co](https://ipapi.co) یا مشابه برو و ببین IP نمایش‌داده‌شده مال کشور
   سرور کانفیگه، نه IP واقعی گوشیت.
6. **قطع اتصال**: دکمه رو دوباره بزن — باید نوتیفیکیشن VPN از نوار وضعیت گوشی هم پاک بشه.
7. **تست حالت‌های دیگه**: سریع (موازی)، سخت (لیست بزرگ + تلاش مجدد)، ثابت، آمریکا — هرکدوم
   استراتژی جست‌وجوی متفاوتی دارن که در `ArkaViewModel.kt` (searchFast/searchHard/searchFirstHealthy)
   پیاده‌سازی شده.

### اگه اتصال وصل نشد یا سریع قطع شد
- ممکنه فرمت لینک با `ConfigConverter` سازگار نباشه (مثلاً یک پارامتر نادر Xray). با Logcat
  (`adb logcat | grep -i xray`) می‌شه دید دقیقاً کجا خطا داد.
- بعضی کانفیگ‌ها REALITY یا پروتکل‌های خیلی خاص دارن که ممکنه نیاز به تنظیم دستی بیشتری داشته باشن.
